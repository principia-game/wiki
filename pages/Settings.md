This page documents all the settings in the Principia settings menu as they exist in the non-Android versions of the game.

[toc]

## Graphics

- **Enable shadows**

	Enables shadows. Recommended to restart the game afterwards to prevent graphical glitches from happening.

- **Shadow quality**

	Smooth (prettier) or sharp (faster) shadows.

- **Shadow resolution**

	The resolution the shadows are rendered at.

- **Enable AO**

	Enables Ambient Occlusion which adds subtle shading behind objects.

- **AO map resolution**

	The resolution at which Ambient Occlusion maps are rendered.

- **Enable bloom**

	Adds a subtle glow effect to bright objects.

- **Gamma correction**

	HDR-like lighting improvements.

- **Vertical sync**

	Synchronises the game's framerate to your monitor's refresh rate. Disabling will unlock the frame limiter and cause unnecessary strain on your hardware, and cause speed issues due to the unlocked framerate generally being pretty high. (Principia is not a demanding game)

## Audio

- **Volume**

	Control the volume level for Principia.

- **Mute all sounds**

	Mute the game, overriding the volume slider.

## Controls

- **Enable touch controls**

	Enable touchscreen controls and other touch-related behaviour.

- **Alternate keyboard-only adventure controls**

	Enable an alternate adventure control scheme which only uses the keyboard. Arrow keys to move and aim, Ctrl to attack, PgUp/PgDown to change layers.

- **Camera speed**

	Controls how fast the camera moves when panning around.

- **Smooth camera movement**

	Enables smooth camera movement when panning around.

- **Zoom speed**

	Controls how fast the camera zooms in and out.

- **Smooth zooming**

	Enables smooth camera zooming.

- **Enable cursor jail**

	Lock the cursor inside the game window while playing a level.

- **Enable RC cursor lock**

	Lock the cursor while controlling RC widgets.

- **Widget sensitivity**

	Controls the mouse-movement-sensitivity used to control sliders, radials and fields using the hotkey mode.

## Interface

- **UI scale**

	Controls the game's UI scale. Requires a restart to take effect.

- **Fullscreen**

	Enable fullscreen mode. Requires a restart to take effect.

- **Resizable window (BETA)**

	Allow the window to be resized. **NOTE:** Principia does not support resizing while in-game. Things will break.

- **Autosave screen size**

	Automatically save the current screen size when the window is resized, for next time the game is launched.

- **Automatically submit highscores**

	Always submit highscores for levels that have it enabled.

- **Ask before submitting highscore**

	Always ask before submitting highscores in levels.

- **Display FPS**

	Display the current framerate in the top left corner of the screen. Graph shows a brief historical graph of the framerate over time.

## Sandbox

- **Hide tips & tricks**

	Hide the tips & tricks dialog that appears when opening the sandbox.

- **Display object ID**

	Display the unique ID and object ID of the selected object in the sandbox.

- **Display grapher value**

	Display the current exact value of [[Grapher]] objects.

- **Display wireless frequency**

	Display the frequency of [[Receiver]] and [[Mini Transmitter]] when paused and zoomed in.

- **Do not confirm quitting sandbox adventure**

	Do not show a confirmation dialog when attempting to quit a sandbox adventure level.

- **Menu scroll speed**

	Controls how fast the sandbox object picker menu scrolls when dragging it.

- **Smooth menu scrolling**

	Whether the sandbox object picker menu's scroll should be smooth or not.
