Principia is a physics-based sandbox game with an extensive set of features, many of which are of interest for educational (edtech) purposes. Since the game's original release in 2013, there has been an entire generation who played the game in their youth and have gone on to successful STEM careers thanks to an interest originally sparked by Principia. Now that Principia is free and under a permissive open source license, this makes it great for adoption in educational settings.

Currently there are no known cases of Principia being officially used in educational settings, but the game has great potential as an edtech tool. This page aims to provide motivations for Principia's merits for educational adoption, as well as resources for those wishing to make use of Principia in education.

## Pitch
Some of the use cases for Principia in question are the following:

- The sandbox allows you to build contraptions in a side-view such as vehicles, as well as structures such as bridges. Using the physics simulation you can make them dynamic to test their stability and functionality.
- The physics simulation in Principia is based on Box2D. While it is a physics engine designed for games and not a perfect scientific simulation of the real world, it still provides a good approximation of real-world physics for teaching fundamental concepts.
- The game's circuitry system is fairly fantasy-based, but the signaling system is still based on real-world electronics and circuitry with objects such as the logic gates.
- The LuaScript object allows you to code in the easy-to-learn Lua programming language. The capabilities of the API range from being able to draw custom sprites to controlling the in-game physics simulation in different ways, in addition to acting as a programmable circuit using its own input and output sockets.
- For higher levels, the Principia open source project itself may be of interest. Being originally a commercially developed game turned open source, the game still largely reflects its roots as a proprietary game while also being free for anyone to study its source code. This makes it a useful and accessible insight of real-world game development practices and the many compromises along the way to get a game to market.

The technical merits of Principia are the following:

- **Free with no restrictions**: Principia is free for anyone to download and deploy in any setting regardless of the structure of your educational organisation thanks to the game's permissive BSD 3-Clause license. No fees or permissions are required to use Principia.
- **Cross-platform**: Primary platforms are Windows, Linux and Android. The game can even be run in a web browser for deployment on locked down devices such as Chromebooks.
- **Low system requirements**: Principia's system requirements are very low and should be able to run on any hardware that may be available in an educational setting, even if it is not the latest.
- **Open Source**: Principia is licensed under the BSD 3-Clause license allowing you to inspect and modify the game's source code for any purpose, including making your own tailor made versions of the game.
- **Active community**: Principia is an actively developed open source project with a responsive maintainer. If you choose to contribute back to the game's wider ecosystem, you can do so with confidence that it will make an impact for those who show up after you rather than being locked away in a proprietary ecosystem.
